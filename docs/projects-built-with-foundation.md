# Projects Built from Foundation

## trinthlo.com

A professional website using Foundation as its underlying application and content-management base.

Site: [trinthlo.com](https://trinthlo.com)

## Books — book.trinthlo.com

A specialized application for managing novels. It demonstrates extending the common account and application structure with a domain-specific system rather than modifying Foundation to understand the domain itself.

Site: [book.trinthlo.com](https://book.trinthlo.com)

## Maisie's — maisies.trinthlo.com

An e-commerce application that extends Foundation into a substantially larger system. It demonstrates how the same starting architecture can support products, shopping, and transactional functionality while keeping those concerns outside the reusable Foundation core.

Site: [maisies.trinthlo.com](https://maisies.trinthlo.com)

## Why these examples matter

The three applications are intentionally different. Together they show Foundation serving as a common starting point for a conventional website, a specialized business application, and a full e-commerce application.
